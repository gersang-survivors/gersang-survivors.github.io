# 巨商 Survivors（Gersang Survivors）

以《巨商》為藍本嘅生存類（Vampire Survivors-like）瀏覽器遊戲。角色、轉職路線、合成配方、怪物、地圖、掉落同裝備全部嚟自[巨商全能百科](https://gersang-wiki.github.io/)嘅 `data.json`，再改編成適合 Survivors 玩法嘅數值。

**直接玩：** https://gersang-survivors.github.io/

## 玩法

- 揀主角：**曹鐵西**（獵人 → 神弓）或 **李明花**（大商人 → 砲手）。
- 每局 10 分鐘：WASD / 方向鍵移動（手機拖動畫面），攻擊全自動。第 5 分鐘出中首領，第 10 分鐘出地圖首領，打低就平定該地圖、開放下一張。
- 開局只帶出戰名單第一位傭兵，其餘要喺局內升級時「招募」先會上場。
- 局內升級三選一：招募傭兵、陣型（方陣、雁行陣、魚鱗陣、鶴翼陣、層陣、方圓陣，原作效果，一次只用一種）、精靈（原作 33 隻同效果文字）、傭兵攻擊 / 攻速 / 技能強化。全部只限該局。
- 合擊技：原作規則，指定兩隻傭兵同時上場會自動發動，例如雷戰車 + 龜甲車 → 召喚不死鳥。
- 行商人賣原作道具（人蔘、人蔘酒、崔家藥丸）。
- 每 75 秒出精英怪，打低掉寶箱（稀有選項：免費招募、高階精靈、技能覺醒）。
- 局完後上過場嘅傭兵攞全數經驗、冇上場攞一半（輸咗都有），永久升級喺營地。
- 局完後經驗、銀兩、戰利品全部帶返營地（撤退都保留）。

## 營地（長期養成）

| 系統 | 內容 |
| --- | --- |
| 傭兵 | 永久等級（用巨商原版經驗表），8 格裝備（武器、盔甲、頭盔、手套、腰帶、鞋子、戒指、飾物），兵器類型限制照原作 |
| 轉職 | 原作路線，例如 弓手 →(Lv40) 李舜臣 →(Lv90) 龜甲車 →(Lv100) 真龜甲車 |
| 合成所 | 原作配方，例如 石爺爺 + 四不像 + 鹿 → 巨山；巨山 + 白龍 + 鐮刀者 → 混沌 / 雷龍 |
| 訓練所 | 朝鮮訓練所 8 種基礎傭兵 |
| 收服 | 打怪有機會收服怪物傭兵（鹿、九尾狐、白虎、石爺爺…） |
| 市場 / 倉庫 | 村莊武器店、轉職合成材料；賣戰利品 |

目前收錄朝鮮 54 隻傭兵、12 張朝鮮地圖。需要其他國傭兵嘅傳說合成（神弓朱蒙、公子崔茂宣、道士洪吉童…）會顯示「未開放」，之後版本加入。

## 美術

網上版本所有角色都係程式生成嘅原創像素圖，**冇使用巨商原作素材**。

### 本機原作素材模式（只限自己部電腦）

1. 下載呢個 repo，同埋你嘅巨商百科 repo。
2. 將百科 repo 入面嘅 `rp` 同 `ip` 兩個資料夾，複製入呢個 repo 嘅 `assets-local/`（變成 `assets-local/rp/`、`assets-local/ip/`）。
3. 喺呢個 repo 資料夾行 `python -m http.server`，用 Chrome 或 Edge 開 http://localhost:8000/ 。

遊戲會自動用原作 8 方向圖同待機動畫；冇呢兩個資料夾就照用原創像素圖。`assets-local/` 已列入 `.gitignore`，唔會上傳。巨商素材屬 Joyon Entertainment 所有，只可以自己用，唔好公開發佈。

## 遊戲化改編（非原作）

以下係為咗 Survivors 玩法而設，唔係巨商原作內容：每局 10 分鐘同首領時間、精英怪同寶箱、局內「攻擊 / 攻速 / 技能強化」卡、原作數值轉換成遊戲數值嘅公式、陣型同精靈效果嘅放大比例、行商人道具回復量、合成材料數量縮減做 1/5、主角轉職等級（30 / 100）、局後經驗分配（上場全數、冇上場一半）。

## 開發

純 HTML5 Canvas + 原生 JavaScript，冇 build 步驟。

```
python -m http.server    # 開 http://localhost:8000/
python tools/extract.py <wiki>/data.json src/gsdata.js   # 百科資料更新後重新生成
```

- `src/gsdata.js`：由 `tools/extract.py` 從 wiki 生成（唔好手改）
- `src/rules.js`：巨商數值 → 遊戲數值嘅轉換、轉職/合成/裝備規則
- `src/main.js`：戰鬥、局內升級、繪圖
- `src/camp.js`：營地介面同存檔（localStorage）
- `src/render.js`：像素美術生成

非官方同人作品，與 Joyon Entertainment 無關；「巨商」為其權利人所有。
