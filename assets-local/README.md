# 本機素材（Local assets）

呢個資料夾入面嘅檔案**唔會**上傳到 GitHub（見 `.gitignore`）。

## 原作素材模式

將巨商百科 repo 嘅 `rp/` 同 `ip/` 複製入嚟（`assets-local/rp/0.json` 存在就會自動啟用），用 Chrome / Edge 經本機伺服器開遊戲。

## 自訂圖片

亦可以放 PNG 同 `sprites.json`（sprite key 對應檔名）取代個別圖，例如 `{"player_0": "a.png"}`。常用 key：`merc_<傭兵id>_0/1`、`mon_<怪物id>_0/1`、`peddler_0/1`。
